# Ultimate Launcher

A Pixel-inspired Android launcher built with a clean Launcher3-style architecture.

## Project goals

- Reliable home-screen workspace and cross-page drag-and-drop
- App drawer with category organization and search
- Material You / wallpaper-aware colors
- Frosted-glass surfaces with graceful fallbacks
- Persistent workspace state using Room
- Offline-first behavior

## Build

Open the project in Android Studio and sync Gradle. The GitHub Actions workflow builds a debug APK on pushes and pull requests.

> This project is an independent launcher inspired by Android's open-source Launcher3 architecture. It does not include proprietary Pixel Launcher code.
